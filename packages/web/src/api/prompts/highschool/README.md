# Fachmodule — Schule (Abitur, Bac, A-Level)

Gleiche Fächer, anderes Niveau: keine Vektorrechnung ohne Einführung, keine
DGL, Notation des Schulbuchs, Bezug zu den Operatoren der Abiturprüfung
(„berechnen“, „begründen“, „skizzieren“).

Geplante Module: `mathematik.ts` (Analysis, Stochastik, Lineare Algebra —
Abitur), `mechanik.ts` (Kräfte, Hebel, schiefe Ebene — Physik Sek II),
`elektrotechnik.ts` (Stromkreise, Ohm, Kirchhoff — Physik Sek II),
`datenverarbeitung.ts` (Informatik Sek II: Python, Struktogramme).

Aufbau wie in `../international/README.md`; `curriculumFor()` liefert
`"highschool"`, sobald das Profil eine Schulstufe kennt.
