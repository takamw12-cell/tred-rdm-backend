# Drapeaux des Länder (`de-xx.svg`)

Source : Wikimedia Commons, fichiers « Flag of <Land>.svg », tous marqués
**Public domain** (vérifié le 2026-11-06 via l'API Commons). En Allemagne, les
drapeaux officiels des Länder sont des actes officiels sans droit d'auteur
(§ 5 UrhG). Fichiers copiés tels quels, contrôlés avant intégration : aucun
script, aucun gestionnaire d'événement, aucune référence externe.
