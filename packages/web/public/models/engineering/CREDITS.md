# Modèles d'ingénierie — sources et licences

## turbofan.glb

- **Titre** : « Turbofan Jet Engine Cutaway »
- **Source** : Grab3D, page `grab3d.com/models/vehicles/jet-engine/`, fichier
  `jet-engine.glb` (2,77 Mo, 39 382 triangles, textures PBR 2048 px),
  téléchargé le 2026-11-16.
- **Licence** : CC0 1.0 Universal (domaine public) — usage commercial et
  modification permis, aucune mention exigée. Texte lu dans le `LICENSE.txt`
  fourni avec le modèle : « Grab3D has waived all copyright and related or
  neighboring rights to the 3D models, textures and images in this package. »
- **Origine déclarée par l'auteur** : modèle construit par scripts Blender
  (scripts écrits avec un assistant de code IA ; ni la géométrie ni les
  textures ne sortent d'un modèle génératif). C'est une coupe pédagogique
  GÉNÉRIQUE d'un turboréacteur double flux à deux arbres, pas la CAO d'un
  moteur réel : soufflante de 20 aubes, 3 étages basse pression, 5 étages
  haute pression, chambre annulaire, turbine 1 + 3 étages.
- **Modifications** : simplification légère, compression meshopt, textures
  converties en WebP (`gltf-transform optimize`) → 865 Ko. Dans l'app, agrandi
  1,5 fois ; le rotor tourne autour de son axe.
